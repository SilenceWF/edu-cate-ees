# edu-cate-ees

**Πλατφόρμα ανοιχτού κώδικα για ευαισθητοποίηση στην ασφάλεια, αποδοχή πολιτικών και τεκμηρίωση εκπαίδευσης κατά ISO/IEC 27001 και NIS2.**

[English](README.md) · [Οδηγός εταιρικού πακέτου](docs/PACK_GUIDE.md)

Οι εργαζόμενοι ολοκληρώνουν τρία σύντομα βήματα: αποδέχονται τις πολιτικές της εταιρείας, διαβάζουν σύντομες εκπαιδευτικές κάρτες και περνούν ένα σύντομο τεστ. Με την επιτυχία κατεβάζουν βεβαίωση. Κάθε βήμα καταγράφεται με ώρα, διεύθυνση IP και εγγραφή σε αρχείο ενεργειών που δεν τροποποιείται. Έτσι έχετε τα τεκμήρια που ζητούν οι ελεγκτές για ISO/IEC 27001 (§7.2, §7.3, Α.6.3), Ν. 5160/2024 (NIS2) και ΚΥΑ 1689/2025.

Ό,τι αφορά τη συγκεκριμένη εταιρεία (όνομα, λογότυπο, χρώματα, πολιτικές, ενότητες, ερωτήσεις, ομάδες, προσωπικό) βρίσκεται σε ένα **εταιρικό πακέτο**: έναν φάκελο με απλά αρχεία YAML.

## Δυνατότητες

- **Τρία βήματα για τον εργαζόμενο.** Πολιτικές (βασικοί κανόνες, πλήρες έγγραφο, υπεύθυνη δήλωση) → εκπαιδευτικές κάρτες → τυχαίες ερωτήσεις με άμεση εξήγηση και επανάληψη → βεβαίωση PDF.
- **Λειτουργία Kiosk** για προσωπικό παραγωγής και αποθήκης χωρίς email. Ο προϊστάμενος ξεκλειδώνει ένα κοινό tablet με PIN. Κάθε εργαζόμενος βρίσκει το όνομά του και πληκτρολογεί τον δικό του κωδικό, διαβάζει τους κανόνες, απαντά και υπογράφει ψηφιακά.
- **Πίνακας ελέγχου για Υ.Α.Σ.Π.Ε. και HR.** Δείκτες, πρόοδος ανά ομάδα με τα χρώματα του οργανογράμματος, φίλτρα και υπενθυμίσεις.
- **Εισαγωγή από Excel** με προεπισκόπηση. Το χρώμα φόντου της στήλης Β γίνεται χρώμα τμήματος. Η επανεισαγωγή δεν χάνει την πρόοδο.
- **Εξαγωγές για έλεγχο.** Μητρώο συμμόρφωσης (Excel, 3 φύλλα), εκτυπώσιμο παρουσιολόγιο A4 με στήλη υπογραφής και πλήρες αρχείο ενεργειών.
- **Δια ζώσης εκπαιδεύσεις** με καταγραφή παρουσιών.
- **Κύκλοι εκπαίδευσης.** Νέος κύκλος κάθε χρόνο με διατήρηση ιστορικού. Νέα έκδοση πολιτικής ζητά επαναποδοχή μόνο αυτής.
- **Επεξεργασία περιεχομένου από τον browser** και εξαγωγή ξανά σε πακέτο.
- **Σύνδεση με Microsoft 365 (Entra ID)** και προαιρετικά με email και κωδικό.
- **Ελληνικά και αγγλικά.**
- **Λειτουργεί σε εσωτερικό δίκτυο.** Δεν φορτώνει τίποτα από CDN.

## Γρήγορη εκκίνηση (τοπικά)

Απαιτούνται PHP 8.3+ (με `intl`, `zip`, `gd`, `pdo_sqlite`), Composer και Node 20+.

```bash
git clone https://github.com/SilenceWF/edu-cate-ees.git && cd edu-cate-ees
```

```bash
composer install && npm install && npm run build
```

```bash
cp .env.example .env && php artisan key:generate && touch database/database.sqlite && php artisan migrate
```

```bash
php artisan pack:install packs/demo
```

```bash
php artisan serve
```

Ανοίξτε το http://localhost:8000. Λογαριασμοί δείγματος (κωδικός `password`): `admin@helios-foods.example`, `hr@helios-foods.example`, `supervisor@helios-foods.example` (PIN Kiosk `2468`), `employee@helios-foods.example`.

## Με Docker (εφαρμογή + MySQL + Nginx)

```bash
cp .env.example .env
```

Στο `.env` ορίστε `APP_URL`, `DB_PASSWORD`, `DB_ROOT_PASSWORD` και `APP_KEY` (δείτε το [README.md](README.md#run-with-docker-app--mysql--nginx)). Μετά:

```bash
docker compose up -d --build
```

```bash
docker compose exec app php artisan pack:install packs/<φάκελος-εταιρείας>
```

## Εισαγωγή του Excel με το προσωπικό

**Διαχείριση → Εισαγωγή Excel.** Μορφή: Α = ομάδα εκπαίδευσης, Β = τμήμα (με το χρώμα του οργανογράμματος ως φόντο κελιού), Γ = ονοματεπώνυμο, Δ = τύπος εκπαίδευσης (π.χ. «Βασική» → πρόγραμμα παραγωγής/αποθήκης, «Διαχειριστών» → Πληροφορική), Ε = email (προαιρετικό). Πρώτα βλέπετε τις αλλαγές και μετά επιβεβαιώνετε.

## Σύνδεση με Microsoft Entra ID

1. Entra admin centre → **App registrations → New registration**.
2. Redirect URI (Web): `https://<διεύθυνση>/auth/microsoft/callback`.
3. **Certificates & secrets** → νέο client secret.
4. Στο `.env`: `MICROSOFT_CLIENT_ID`, `MICROSOFT_CLIENT_SECRET`, `MICROSOFT_TENANT_ID`.

Συνδέονται μόνο όσοι υπάρχουν στο μητρώο. Όταν λειτουργήσει, ορίστε `ENABLE_LOCAL_AUTH=false`.
